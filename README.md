## Tech Stack

* **HTML5** – Semantic layouts and modular components
* **CSS3** – Custom responsive styles and grid layouts[cite: 1, 3]
* **JavaScript (ES6+)** – Interactive scripts and component loaders (`include.js`)[cite: 1, 3, 5]
* **FontAwesome 6** – Interface icons[cite: 1, 6, 8]
